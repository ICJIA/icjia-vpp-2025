Development Tools & Resources

This document provides a comprehensive list of tools, frameworks, and resources used in the Violence Prevention Plan for Illinois project. These resources are essential for developers working on this project.

Core Framework & UI

App Framework

Nuxt 4 - The Vue.js framework for building modern web applications with server-side rendering, static site generation, and more.

  • Link: https://nuxt.com/
  • Purpose: Primary application framework providing routing, SSR, and build tooling

UI Framework

Vuetify - Material Design component framework for Vue.js applications.

  • Link: https://vuetifyjs.com/
  • Purpose: UI component library providing Material Design components and theming

Design System

Material Design - Google's design system providing guidelines for creating intuitive and beautiful user interfaces.

  • Link: https://material.io/design
  • Purpose: Overall design principles and guidelines that inform the project's visual design and user experience

Theme Generation

Vuetify Theme Generator - Online tool for generating custom Vuetify themes.

  • Link: https://theme.oliverrr.net/config
  • Purpose: Generate custom color schemes and themes for Vuetify components

Content & Documentation

Markdown

ICJIA Markdown Editor - Online markdown editor and preview tool.

  • Link: https://markdown.icjia.cloud
  • Purpose: Edit and preview markdown content used throughout the project

Documentation

JSDoc - JavaScript documentation generator for creating API documentation.

  • Link: https://jsdoc.app/
  • Purpose: Generate documentation from code comments and maintain code documentation standards

Search & Typography

Search

Fuse.js - Lightweight fuzzy-search library for JavaScript.

  • Link: https://fusejs.io/
  • Purpose: Provide fuzzy search functionality across all site content

Fonts

Google Fonts - Web font service providing optimized fonts for web use.

  • Link: https://fonts.google.com/
  • Purpose: Typography and font selection for the project

Icons

Google Icons - Material Design icon library with thousands of free icons.

  • Link: https://fonts.google.com/icons
  • Purpose: Material Design icons for UI elements and visual communication

Material Design Icons - Community-driven icon library with extended Material Design icons.

  • Link: https://pictogrammers.com/library/mdi/
  • Purpose: Extended icon set beyond Google's Material Icons, providing additional design options

Development & Source

Source Code

GitHub Repository - Project source code and version control.

  • Link: https://github.com/ICJIA/icjia-vpp-2025
  • Purpose: Version control, issue tracking, and collaborative development

Accessibility Resources

Federal Guidelines

Web Content Accessibility Guidelines (WCAG) 2.1 - International accessibility standards.

  • Link: https://www.w3.org/WAI/WCAG21/quickref/
  • Purpose: Federal accessibility compliance standards (AA level required)

Illinois State Guidelines

Illinois Information Technology Accessibility Act (IITAA) 2.1 Standards - State-specific accessibility requirements.

  • Link: https://doit.illinois.gov/initiatives/accessibility/iitaa/iitaa-2-1-standards.html
  • Purpose: Illinois state accessibility compliance requirements

Project Accessibility Documentation

Project Accessibility Information - This project's accessibility documentation and audit logs.

  • Link: /accessibility/documentation
  • Purpose: Project-specific accessibility features, testing, and compliance documentation
