debug

boolean | undefined

Debug mode When enabled, displays the complete raw JSON representation of the content data below the rendered content. This is useful for development and debugging to understand the content structure and troubleshoot rendering issues. The debug display shows all keys and values in the content object, including metadata, body content, and any other properties returned by the content API. It is formatted with proper indentation for readability and placed in a visually distinct section below the rendered content.

Default: "false"
