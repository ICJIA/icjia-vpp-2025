    Module ErrorHandlerPlugin

    Error Handler Plugin

    Intercepts and handles common errors in a more graceful way. Specifically targets 404 "Page not found" errors to prevent console noise in production.

    This plugin overrides the console.error method to filter out expected 404 errors in production, while preserving the original behavior for all other errors and in development mode. Hydration errors are never suppressed as they indicate real issues.

    Features:

    • Filters 404 errors in production to reduce console noise
    • Preserves all error logging in development mode
    • Never suppresses hydration errors (critical for debugging)
    • Maintains original console.error functionality for other errors
    • Pattern matching for various 404 error formats
